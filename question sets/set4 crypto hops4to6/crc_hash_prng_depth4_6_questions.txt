CRC / MINI-HASH / PRNG SET — DEPTHS 4 TO 6

================================================================================
Problem 1 | depth 4 | toy_crc4

Toy CRC-4 challenge — 4 hops

Start with R = 0011.
Input bits: 0010

For each input bit b:
  f = MSB(R) XOR b
  R = (R << 1), keeping only 4 bits
  if f = 1, set R = R XOR 0011

After 4 updates, what is R in 4-bit binary?

Problem 2 | depth 4 | mini_hash

Mini-hash challenge — 4 hops

Start with H = 206.
Data values: 18, 8, 28, 10

For each x, perform one round:
  H = ((H XOR x) * 5 + 7) mod 256

After 4 rounds, what is H?

PRNG challenge — 4 hops
