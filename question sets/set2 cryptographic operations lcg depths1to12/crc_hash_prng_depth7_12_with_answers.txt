Problem 1 | CRC-7 | depth 7 | toy_crc4

Toy CRC-4 challenge — 7 hops

Start with 4-bit register R = 0011.
Input bits: 0010110

For each input bit b, perform exactly one update:
  f = MSB(R) XOR b
  R = (R << 1), keeping only 4 bits
  if f = 1, set R = R XOR 0011

After consuming all 7 bits, what is R in 4-bit binary?

ANSWER: 0001
